# S21-SlotMachine

Chrome-расширение для автообновления календаря ревью Школы 21 и записи на подходящие слоты без перезагрузки страницы.

## Установка

1. Скачай ZIP из **Releases** и распакуй.
2. Открой `chrome://extensions`, включи «Режим разработчика» и загрузи распакованную папку через «Загрузить распакованное расширение».

## Использование

Открой календарь регистрации на ревью, выбери параметры в панели сверху. «Старт» запускает таймер, «↻» обновляет один раз, «Стоп» останавливает. Для записи включи «Автоматическую регистрацию», выбери тип и срок: расширение запишет на подходящие слоты выбранной недели до выполнения счётчика.
